# ADR-0003：评分采用维度加权 + 严重问题封顶

- 状态：已采纳
- 日期：2026-10-22

## 背景

早期只做维度加权平均。结果：一条连续 20 次重复调用的死循环轨迹拿到 96 分 A 级；一条含 4 个严重问题的轨迹拿到 84 分 B 级。加权平均让「一个维度彻底崩坏」被其余三个满分维度稀释，与质检门禁的用途相悖。

## 决策

两层评分：

1. **维度扣分**：按 `scoreImpact × 严重度系数` 扣分；单条规则最多计 3 次，避免一个系统性问题把维度打到 0 后掩盖其他问题。
2. **总分封顶**：按**不同 error 级规则数**（不是命中次数）限制总分——≥1 条 74（C）、≥3 条 54（D）、≥5 条 39（E）。
3. 同时保留 `rawOverall`，界面显示「严重问题封顶」，报告注明原始加权分。

## 后果

- 「有没有严重问题」成为一等信号，不再被平均值抹平；
- 同一问题命中 40 次仍只算一条规则，避免重复计权；
- 封顶阈值是产品判断，写在报告中可被审计；调整需同步 golden master。
