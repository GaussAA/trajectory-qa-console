# ADR-0004：分析端口保留同步与 worker 两个适配器

- 状态：已采纳
- 日期：2026-10-22

## 背景

解析与规则在主线程同步执行。小轨迹无感，MB 级轨迹会冻结界面数秒，且无法取消。但 worker 并非处处可用：测试环境（jsdom / node）、旧浏览器、单文件分发下的加载失败都可能没有 Worker。

## 决策

定义 `AnalyzerPort { analyze(request, signal) }`，提供两个适配器：

- **同步**：默认；测试、小输入、无 Worker 环境；
- **worker**：`?worker&inline` 内联进单文件；超过 256k 字符自动切换，支持 `AbortSignal` 取消。

组合适配器在 worker 启动失败或运行中报 `analysis-failed` 时**自动降级**为同步，绝不因线程问题丢用户数据。

## 后果

- 两个适配器才构成真实接缝；单适配器只是多一层间接；
- 降级路径有测试覆盖（worker 崩溃 → 同步成功）；
- 代价是产物增大约 150 KB（worker 内联了 core 代码），换来主线程不阻塞。
